# Provider icons

The DeepSeek, MiniMax, SiliconFlow, Volcengine, OpenAI, and Ollama SVGs are copied from
[`lobehub/lobe-icons`](https://github.com/lobehub/lobe-icons), distributed under
the repository's MIT license (static package `@lobehub/icons-static-svg@1.95.1`).
The catalog in `extension/lib/provider/presets.ts`
maps each provider to one local asset so future providers can be added without
changing the picker implementation.
